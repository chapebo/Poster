## Пользовательские сценарии

- **Гость:**  
  `Главная` → `Каталог` → `Детальная страница` → `(Форма записи)` → `Регистрация` → `Авторизация` → `[Пользователь]`

- **Пользователь:**  
  `Главная` → `Каталог` → `Детальная страница` → `Форма записи` → `Личный кабинет` → `Мои заявки`

- **Администратор:**  
  `Админ-панель` → `Управление мероприятиями / Управление заявками` → `Изменение данных`
