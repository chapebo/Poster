# Структура сайта

## Публичная часть

### 1. Главная страница
- **Описание:** Приветственная страница с информацией о сервисе, блоком популярных категорий и ближайшими мероприятиями
- **Элементы:**
  - Навигационное меню (Логотип, Каталог, Войти, Зарегистрироваться)
  - Приветственный блок
  - Быстрый поиск мероприятий
  - Популярные категории
  - Футер

### 2. Каталог мероприятий
- **Описание:** Основной раздел для поиска и фильтрации событий
- **Элементы:**
  - Строка поиска по названию или теме
  - Фильтры:
    - Дата (выпадающий список)
    - Категория (выпадающий список)
    - Местоположение (выпадающий список)
  - Сетка карточек мероприятий
  - Пагинация
- **Карточка мероприятия содержит:**
  - Изображение события
  - Название
  - Дату и время проведения
  - Краткое описание
  - Ссылку «Подробнее»

### 3. Детальная страница мероприятия
- **Описание:** Полная информация о выбранном событии
- **Элементы:**
  - Галерея изображений
  - Название мероприятия
  - Подробное описание
  - Дата и время проведения
  - Место проведения (адрес, карта)
  - Стоимость билетов
  - Количество доступных мест
  - Категория события
  - Кнопка «Записаться/Забронировать»
  - Информация об организаторе

### 4. Страница авторизации
- **Описание:** Форма входа для зарегистрированных пользователей
- **Элементы:**
  - Поле Email
  - Поле Пароль
  - Кнопка «Войти»
  - Ссылка «Нет аккаунта? Зарегистрироваться»
  - Ссылка «Забыли пароль?»

### 5. Страница регистрации
- **Описание:** Форма создания нового аккаунта
- **Элементы:**
  - Поле Имя
  - Поле Email
  - Поле Пароль
  - Поле Подтверждение пароля
  - Чекбокс согласия с условиями использования
  - Кнопка «Зарегистрироваться»
  - Ссылка «Уже есть аккаунт? Войти»

### 6. Форма бронирования
- **Описание:** Оформление заявки на участие в мероприятии
- **Элементы:**
  - Информация о мероприятии
  - Выбор количества билетов/мест
  - Контактные данные
  - Способ получения билетов
  - Итоговая стоимость
  - Кнопка «Подтвердить бронирование»

## Личный кабинет пользователя

### 1. Дашборд личного кабинета
- **Описание:** Основная страница пользователя с обзорной информацией
- **Элементы:**
  - Шапка с аватаром и именем пользователя
  - Боковое меню навигации
  - Краткая статистика (активные заявки, предстоящие мероприятия)
  - Быстрые действия
  - Кнопка «Выйти»

### 2. Мои заявки
- **Описание:** История всех бронирований и заявок пользователя
- **Элементы:**
  - Таблица заявок с колонками:
    - Событие (название мероприятия)
    - Дата (дата и время бронирования)
    - Статус (Новая, Подтверждено, Отменено, Завершено)
    - Действия (кнопки в зависимости от статуса)
  - Фильтры по статусу и дате
  - Пагинация

### 3. Редактирование профиля
- **Описание:** Управление личными данными и настройками аккаунта
- **Элементы:**
  - Загрузка/изменение аватара
  - Поле Имя
  - Поле Email
  - Поле Телефон
  - Смена пароля
  - Кнопка «Сохранить изменения»
  - Кнопка «Удалить аккаунт»

## Административная часть

### 1. Панель администратора (Обзор)
- **Описание:** Дашборд с общей статистикой и быстрыми действиями
- **Элементы:**
  - Статистика:
    - Всего мероприятий
    - Активных заявок
    - Пользователей
    - Предстоящие события
  - Графики и диаграммы
  - Последние заявки
  - Быстрые действия

### 2. Управление мероприятиями
- **Описание:** CRUD-интерфейс для управления каталогом событий
- **Элементы:**
  - Таблица мероприятий с колонками:
    - ID
    - Название
    - Дата проведения
    - Категория
    - Статус (Активно, Архив, Черновик)
    - Количество мест
  - Кнопка «Добавить мероприятие»
  - Фильтры по статусу, дате, категории
  - Поиск по названию
  - Действия в строке:
    - Редактировать
    - Архивировать
    - Удалить

### 3. Страница создания/редактирования мероприятия
- **Описание:** Форма добавления или изменения информации о событии
- **Элементы:**
  - Поле Название
  - Текстовый редактор Описания
  - Загрузка изображений
  - Выбор даты и времени начала/окончания
  - Выбор категории (выпадающий список)
  - Поле Место проведения
  - Поле Адрес
  - Интеграция с картой
  - Поле Стоимость билетов
  - Поле Общее количество мест
  - Чекбокс «Бесплатное мероприятие»
  - Кнопки «Сохранить» и «Отмена»

### 4. Управление бронированиями (заявками)
- **Описание:** Просмотр и обработка всех заявок пользователей
- **Элементы:**
  - Таблица заявок с колонками:
    - ID
    - Название мероприятия
    - Пользователь (имя, email)
    - Дата бронирования
    - Количество мест
    - Статус
    - Действия
  - Фильтры:
    - Фильтр по статусу
    - Фильтр по дате
    - Поиск по ID или имени пользователя
  - Массовые действия
  - Экспорт в CSV/Excel

### 5. Изменение статуса заявки
- **Описание:** Модальное окно или отдельная страница для смены статуса
- **Элементы:**
  - Информация о заявке
  - Выпадающий список статусов:
    - Новая
    - Подтверждена
    - Отменена
    - Завершена
  - Поле для комментария
  - Кнопка «Изменить статус»
  - Автоматический пересчёт доступных мест

### 6. Настройки и справочники
- **Описание:** Управление системными настройками и справочниками
- **Элементы:**
  - **Управление категориями:**
    - Список категорий
    - Добавление/редактирование/удаление
  - **Управление локациями:**
    - Список мест проведения
    - Добавление/редактирование/удаление
  - **Настройки сайта:**
    - Общие параметры
    - Email-рассылки
    - SEO-настройки
  - **Управление пользователями:**
    - Список пользователей
    - Блокировка/разблокировка
    - Изменение ролей
